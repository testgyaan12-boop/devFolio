# **App Name**: DevFolio

## Core Features:

- About Me: A section detailing my experience as a full-stack developer with a focus on Java, Spring Boot, and related technologies.
- Skills Showcase: Interactive display of my proficiency in various technologies (Java, Spring Boot, SQL, HTML, CSS, React, Angular, REST APIs, Hibernate, JPA).
- Project Portfolio: Showcase of projects I've worked on, including Finhaatpro and other insurance domain projects, with details on my contributions and technologies used.
- API Integration Demos: Demonstration of my experience integrating with multiple insurance company APIs, highlighting data fetching and processing capabilities.
- Responsive Design: Ensuring the portfolio website is fully responsive and adapts seamlessly to different screen sizes and devices.
- Contact Form: A contact form for potential employers or collaborators to reach out to me.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and modern look.
- Secondary color: Light gray (#F0F0F0) for a clean and uncluttered background.
- Body font: 'Roboto' for readability and a clean aesthetic.
- Headline font: 'Montserrat' for a bold and modern feel.
- Use Font Awesome icons for a consistent and professional look.
- Use a grid-based layout for a structured and organized presentation of content.
- Subtle animations for transitions and interactions to enhance user experience.
